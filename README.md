# BusinessBuddies 🤝

A mobile-friendly project ledger and inventory tracking app for partners who flip thrift, buy storage units, and sell items across eBay, Facebook Marketplace, and private sales.

## 🚀 Live Demo & Setup via GitHub Pages

1. **Upload Files to GitHub**:
   - In this repository (`https://github.com/ericwoodliff54/businessbuddies`), click **Add file** > **Upload files**.
   - Drag and drop `index.html`, `manifest.json`, and `sw.js` (or commit them via git).
   - Commit the changes to the `main` branch.

2. **Enable GitHub Pages**:
   - Go to your repository **Settings** tab.
   - Click **Pages** in the left sidebar (under "Code and automation").
   - Under **Build and deployment > Branch**, select `main` and `/ (root)`, then click **Save**.
   - Within 1–2 minutes, your live app will be accessible at:
     `https://ericwoodliff54.github.io/businessbuddies/`

3. **Install on Phone (PWA)**:
   - Open that URL in Safari (iOS) or Chrome (Android).
   - Tap **Share** > **Add to Home Screen** to run it fullscreen just like a native app.

## ✨ Features Included in this POC:
- **Project Switcher & Setup**: Manage separate storage units or thrift hauls with customized profit splits (e.g., 50/50, 60/40).
- **Photo & Item Intake**: Snap photos of items, set target listing prices, and assign which partner added them.
- **One-Tap "Mark as Sold"**: Record the final sale price, platform fees, who sold it, and who collected the cash.
- **Expense & Receipt Ingestion**: Log out-of-pocket costs (U-Haul, storage unit bid, packing totes) tagged to the paying partner for 100% upfront reimbursement.
- **Real-Time "Profit Pot" & Settlement ("Square Up")**: Automatically calculates exact net balances so partners always know who owes whom down to the penny.
- **Offline Local Storage**: Automatically saves all items, expenses, and partner stats in browser local storage.
