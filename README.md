# Business Buddies 🤝

**Multi Partner Side Hustle Manager**

A mobile-friendly project ledger and inventory tracking app for partners who flip thrift, buy storage units, and sell items across eBay, Facebook Marketplace, and private sales.

## 🚀 Live Demo & Setup via GitHub Pages

1. **Upload Files to GitHub**:
   - In your repository (`https://github.com/ericwoodliff54/businessbuddies`), click **Add file** > **Upload files**.
   - Drag and drop `index.html`, `manifest.json`, `sw.js`, and `logo.jpg`.
   - Commit the changes to the `main` branch.

2. **Enable GitHub Pages**:
   - Go to your repository **Settings** tab.
   - Click **Pages** in the left sidebar (under "Code and automation").
   - Under **Build and deployment > Branch**, select `main` and `/ (root)`, then click **Save**.
   - Within 1–2 minutes, your live app will be accessible at:
     `https://ericwoodliff54.github.io/businessbuddies/`

3. **Install on Phone (PWA)**:
   - Open that URL in Safari (iOS) or Chrome (Android).
   - Tap **Share** > **Add to Home Screen** to run it fullscreen just like a native app.
